# 🐧 Linux Module 3 – Advanced Server Administration

Welcome to my Linux Module 3 practical repository! 🚀

This repository covers advanced Linux server administration topics, including Cockpit web-based management, SSL/TLS security, MariaDB database installation, IPv6 networking, and Postfix mail server configuration.

These practicals are designed for Linux learners, system administrators, cloud engineers, and DevOps beginners who want to gain hands-on experience managing Linux servers and network services.

## 📚 Topics Covered

### 1. Cockpit – Web-Based Linux Management
- Understand Cockpit and its features.
- Install Cockpit on a Linux server.
- Start and enable the Cockpit service.
- Access the web console through a browser.
- Monitor CPU, memory, storage, and network usage.
- Manage system services and view logs.
- Troubleshoot Cockpit connectivity issues.

### 2. SSL and TLS Configuration
- Understand SSL/TLS and encrypted communication.
- Learn about certificates, public keys, and private keys.
- Generate self-signed certificates for lab environments.
- Understand Certificate Signing Requests (CSR).
- Configure TLS certificates for supported services.
- Verify certificates and troubleshoot common errors.
- Learn the importance of certificate validity and secure connections.

### 3. MariaDB Database Installation and Administration
- Understand MariaDB and relational databases.
- Install MariaDB on a Linux server.
- Start and enable the database service.
- Secure the database installation.
- Connect to MariaDB using the command-line client.
- Create databases and tables.
- Create database users and grant privileges.
- Perform basic SQL operations.
- Understand database backup and restoration.

### 4. IPv6 Network Configuration
- Understand IPv4 and IPv6 differences.
- Learn IPv6 address notation and address types.
- Check IPv6 configuration on Linux.
- Configure IPv6 addresses and routes.
- Verify connectivity using `ping` and `ip`.
- Understand default gateways and routing.
- Troubleshoot IPv6 network connectivity.

### 5. Postfix – Mail Server Configuration
- Understand SMTP and email delivery.
- Learn the purpose of Postfix.
- Install Postfix on a Linux server.
- Configure basic mail server settings.
- Start and enable the Postfix service.
- Understand SMTP ports and firewall requirements.
- Inspect mail logs and troubleshoot delivery problems.
- Learn about DNS records, including MX, SPF, DKIM, and DMARC.
- Understand TLS encryption for mail transport.

**Note:** Sending email to external providers may require a valid domain, correct DNS records, appropriate network access, and an authorized SMTP relay.

## 🎯 Learning Objectives

After completing these practicals, learners should be able to:

- Manage Linux servers through Cockpit.
- Understand and configure SSL/TLS certificates.
- Install and administer MariaDB databases.
- Configure and troubleshoot IPv6 networking.
- Install and configure a basic Postfix mail server.
- Monitor services and analyze Linux logs.
- Apply server security and networking fundamentals.

## 💻 Recommended Lab Environment

- CentOS Stream or another compatible RHEL-based distribution
- Red Hat Enterprise Linux (RHEL)
- A Linux virtual machine running on VMware or VirtualBox
- Root or sudo privileges
- A web browser for Cockpit access
- Internet access for package installation
- A test domain for advanced mail server configuration

## ☁️ Relevance to Cloud and DevOps

These skills are useful for Linux server administration, cloud infrastructure management, database hosting, network configuration, secure communication, and mail service troubleshooting in AWS and Microsoft Azure environments.
